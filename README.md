# Anika website

Landing page for Anika, an AI business advisor for SMEs. Plain HTML/CSS/JS with a GSAP + ScrollTrigger (and optional Lenis) motion layer loaded from CDNs.

## Run locally

```bash
node serve.js
```

Then open http://localhost:5391. Add `?nolenis` to the URL to turn off smooth scrolling.

## Structure

- `site/index.html`, `site/styles.css`, `site/motion.js`: the page
- `site/assets/`: images used by the page
- Root images: original design assets
